# Show-Only Preview

The current hosted preview is for demonstrating the family game, not yet for running a real
household.

## Safe To Try

- switch between the three demo family members;
- join and complete demo quests;
- endorse another person's work;
- see Watch Points, gratitude, Home Energy, and reward spending;
- install the preview on a phone home screen.

## Important Limits

- demo progress resets;
- separate phones do not share one live household;
- there is no real sign-in or private family account yet;
- do not enter private child, relationship, financial, custody, or household information;
- the preview is not evidence storage and should not be used for real record keeping.

## Next Production Step

Connect the prepared repository layer to Supabase, enforce household access policies, and
test the join-to-thanks loop on three separate phones. That work is defined in
`docs/NEXT_BATCH.md`.
